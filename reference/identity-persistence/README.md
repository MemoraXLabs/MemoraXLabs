# identity-persistence

This is not a product.
This is a proof of necessity.

MemoraX is the memory layer for long-horizon intelligence.

This reference demonstrates that identity and trajectory
cannot survive execution resets without a persistent memory layer.

## What this demonstrates
- Without persistence, identity resets on every execution
- Trajectory collapses between sessions
- Learning becomes episodic instead of cumulative

With even the simplest persistence mechanism,
identity and experience survive resets.

## Why this matters
Intelligence that cannot remember cannot accumulate.
It can only restart.

This is why a dedicated memory layer is required for
long-horizon systems.

See memorax.py for the minimal demonstration.
